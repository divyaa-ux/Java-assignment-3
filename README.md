Java Assignment 3

Foundations of Java Development

This repository contains my Java Assignment 3 for BCA III Semester.

The assignment focuses on arrays and different types of array operations in Java.

Topics Covered

- 1-D Arrays
- 2-D Arrays
- 3-D Arrays
- Jagged Arrays
- Array Searching
- Array Rotation
- Counting Occurrences
- Finding Maximum and Second Largest Elements
- Matrix Transpose
- Matrix Multiplication
- Matrix Diagonal Operations
- Triangular Matrix
- Boundary Elements
- Sparse Matrix

Programs Included

1-D Array Programs

- Display elements of an array
- Reverse an array
- Sum of array elements
- Count even and odd numbers
- Left rotation
- Count occurrences
- Find second largest element
- Remove duplicate elements

2-D Array Programs

- Sum of matrix elements
- Matrix transpose
- Matrix multiplication
- Diagonal sum
- Upper and lower triangular matrix
- Boundary elements
- Search an element in a matrix
- Sparse matrix

3-D Array Programs

- Display 3-D array
- Count positive and negative numbers
- Find maximum element

Jagged Array Programs

- Create and display a jagged array
- Store and display student marks with different numbers of subjects
- Sort each row of a jagged array

Technologies Used

- Java
- JDK 19 or higher
- Visual Studio Code

How to Run

1. Install JDK 19 or higher.
2. Open the ".java" file in VS Code or any Java IDE.
3. Compile and run the program.
4. Enter the required input in the terminal.
5. Check the output.
